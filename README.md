- www.chinapeixun.org.cn（培训网）

## 使用前提
1. 已在网站购买并开通课程
2. 已完成人脸验证，能正常登录
3. Python 3.6+ 环境

## 快速开始

### 1. 安装依赖
```bash
pip install requests
```

### 2. 获取Cookie（详细步骤）

**第一步：登录网站**
1. 用Chrome或Edge浏览器打开 https://www.chinapeixun.org.cn
2. 输入账号密码登录，完成人脸验证
3. 确认能看到"我的课程"页面，说明登录成功

**第二步：打开开发者工具**
1. 在页面任意位置按 `F12` 键（或右键 → 检查）
2. 顶部切换到 **Application**（应用程序）标签
3. 左侧找到 **Cookies** 文件夹，点击展开
4. 点击下面的 `https://www.chinapeixun.org.cn`

**第三步：复制PHPSESSID**
1. 在右侧Cookie列表中，找到名为 **PHPSESSID** 的那一行
2. 双击它的 **Value** 列，全选复制
3. 只需要复制这一个值就够了

---

**三种粘贴方式都支持（任选一种）：**

| 方式 | 示例（占位符） | 说明 |
|------|--------------|------|
| 只粘贴值 | `xxxxxxxxxxxxxxxxxxxx` | 最简单，直接粘贴复制的那串字符 |
| 完整格式 | `PHPSESSID=xxxxxxxxxxxxxxxxxxxx` | 带key名也可以 |
| 整段Cookie | `PHPSESSID=xxx; play_token=yyy; ...` | 从控制台 `document.cookie` 复制的整段也行 |

> 💡 提示：v2.1版本已加自动预热，不需要特意点开课程再复制Cookie，登录后直接复制就行。

### 3. 运行脚本
```bash
python3 training_course_auto_complete.py
```

### 4. 粘贴Cookie
按提示粘贴Cookie，回车即可开始自动学习。

## 常见问题

**Q: 提示"未找到课程"怎么办？**
A: 说明Cookie已过期或无效。请重新登录网站，再复制新的PHPSESSID。

**Q: 运行中途中断了怎么办？**
A: 直接重新运行即可，服务器端已记录的进度会自动跳过。

**Q: 提示"被锁定"怎么办？**
A: 说明章节顺序错乱了，脚本会自动按顺序解锁，不需要手动处理。

**Q: 是不是必须先点开一个课程才能用？**
A: 不需要。v2.1版本已经加了自动预热功能，启动时会自动访问课程列表页初始化会话，从首页复制PHPSESSID也能直接用。

## 注意事项
- Cookie有时效性，过期后需要重新获取
- 脚本内置0.5秒延时，避免请求过快
- 请遵守网站相关规定，合理使用
